Adicionar aplicação

Abre a aplicação e reproduz som para aparecer na lista. Escolhe o canal de áudio, a página e o slider A–D que a controla no modo de aplicações. Depois guarda: o Utility encaminha o áudio no Windows e mostra o resultado abaixo de cada aplicação.

Aplicações configuradas

Se escolheres um slider ocupado, as duas aplicações trocam de posição. Guardar alterações fecha o modo de aplicações; volta a abri-lo para usar as novas posições.

Liga um Mini para começar.

No hardware: duplo clique no mute de um fader para abrir as aplicações do canal desse fader. Os quatro faders controlam até quatro aplicações por página. Beep recua, mute temporário avança e o mesmo duplo clique sai. Mantém Beep + mute temporário premidos para repor os volumes de referência das aplicações desse canal com áudio ativo. Ao entrar numa página, move cada fader até à posição do volume atual para o ativar.
