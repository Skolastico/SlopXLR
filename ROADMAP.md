# SlopXLR roadmap

These are priorities, not committed release dates.

## Validate the current beta

- Verify normal installation and upgrade on a clean second Windows PC.
- Confirm physical Mini gestures, fader pickup and audible soundboard routing with a repeatable checklist.
- Verify startup after a complete Windows reboot.
- Exercise a real signed public update and failed-update recovery before relying on automatic distribution.

## Broaden hardware coverage

- Validate full-size GoXLR standard controls, effects, sampler, recording, displays and lighting.
- Evaluate custom Full action/application modes separately; they are currently restricted to Mini.

## Distribution and maintenance

- Configure/test the GitHub Actions signing secret and release workflow.
- Assess Windows executable signing before broader public distribution.
- Keep English docs, translation catalogs and release compatibility notes synchronized.

See [VALIDATION.md](docs/VALIDATION.md) for evidence and [COMPARISON.md](docs/COMPARISON.md) for present capability boundaries. Additional platforms and private-repository automatic updates are not currently promised.
